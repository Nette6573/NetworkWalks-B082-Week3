# W3-PM2 – Password Cracking with NetworkWalks Tools

## Objective

Recover the password of the authorized NetworkWalks training PDF `My Locked PDF1.pdf` using the NetworkWalks Hash Calculator and Password Cracker.

## Tools Used

- NetworkWalks Hash Calculator
- NetworkWalks Password Cracker
- Web browser
- Protected training PDF

## Methodology

1. Accessed the NetworkWalks password-cracking training lab.
2. Uploaded the authorized protected PDF to the Hash Calculator.
3. Extracted the PDF password hash.
4. Submitted the hash to the NetworkWalks Password Cracker.
5. Started the dictionary-based password attack.
6. Waited for the tool to identify a matching password.
7. Used the recovered password to open the protected PDF.
8. Verified successful completion of the lab.

## Evidence

Screenshots documenting the completed workflow are available in the `screenshots/` directory. Sensitive hash and password values have been redacted from the public copies.

## Result

The password was successfully recovered using the NetworkWalks Password Cracker and the protected training PDF was successfully opened.

## Ethical Use

This exercise was performed only against the authorized NetworkWalks training material supplied for the internship.
