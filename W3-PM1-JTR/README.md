# W3-PM1 – Password Cracking with JTR

## Objective

Recover the password of the authorized NetworkWalks training PDF `My Locked PDF1.pdf` using John the Ripper (JTR) and Johnny.

## Tools Used

- John the Ripper (JTR)
- Johnny GUI
- PDF hash extraction tool
- Windows PC

## Methodology

1. Obtained the authorized training PDF.
2. Extracted the PDF password hash.
3. Saved the hash locally for the exercise.
4. Loaded the hash into Johnny.
5. Started the password-cracking attack.
6. Recovered the training password.
7. Used the recovered password to open the protected PDF.
8. Verified successful completion using the lab evidence.

## Evidence

Screenshots documenting the completed workflow are available in the `screenshots/` directory. Sensitive hash and password values have been redacted from the public copies.

## Result

The password was successfully recovered in the authorized lab environment and the protected training PDF was successfully opened.

## Ethical Use

This exercise was performed only against the authorized NetworkWalks training material supplied for the internship.
